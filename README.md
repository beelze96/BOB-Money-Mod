# BOB-Money-Mod
Blades of Brim Money mod using Shizuku Privilege 

if you have Shizuku already installed on you device, all you need to do is install a file manager. you can use any file manager that can cutilize Shizuku Privilege, for me I uses Zarchiver. 

after installing the file manager of your choice, grant it an access on shizuku.

now open the ZArchiver app and go to
Android/data/com.sybogames.brim/user_profile/

Using ZArchiver built-in file editor, you can edit and copy the code from [User_Profile.json](https://github.com/beelze96/BOB-Money-Mod/blob/5e6c3c1b24e36affafe8f2bc9542dd18c360f57b/user_profile.json)
